1Sets & Logic

Set notation

A = { x ∈ ℝ | P(x) } — roster form / set-builder notation
  • a ∈ A: a is an element of A; a ∉ A: a is not an element of A.
  • A ⊂ B (A is a subset of B) ⇔ ∀x ∈ A ⇒ x ∈ B.
  • A = B ⇔ A ⊂ B and B ⊂ A.
  • Number of subsets of a set with n elements: 2n.

Set operations

  • Union: A ∪ B = { x | x ∈ A or x ∈ B }
  • Intersection: A ∩ B = { x | x ∈ A and x ∈ B }
  • Difference: A \ B = { x | x ∈ A and x ∉ B }
  • Complement (in ℝ): CℝA = ℝ \ A

Propositions

  • Negation of P: "not P" (symbol ¬P or P̄).
  • Implication P ⇒ Q: "if P then Q". P is sufficient for Q; Q is necessary for P.
  • Equivalence P ⇔ Q: P is necessary and sufficient for Q.

2Functions

Domain & Range

Domain of f(x) = 1/g(x): g(x) ≠ 0
Domain of f(x) = √(g(x)): g(x) ≥ 0

Linear function: y = ax + b (a ≠ 0)

  • Slope = a; y-intercept = b.
  • Increasing if a > 0, decreasing if a < 0.

Quadratic function: y = ax² + bx + c (a ≠ 0)

  • Parabola opens upward if a > 0, downward if a < 0.
  • Vertex: I(−b/2a; −Δ/4a) with Δ = b² − 4ac.
  • Axis of symmetry: x = −b/2a.

Even / Odd function

  • Even: f(−x) = f(x) — graph symmetric about Oy.
  • Odd: f(−x) = −f(x) — graph symmetric about origin O.

3Quadratic Equations & Inequalities

Quadratic equation ax² + bx + c = 0

Δ = b² − 4ac
Δ > 0: two distinct roots x = (−b ± √Δ) / 2a
Δ = 0: double root x = −b / 2a
Δ < 0: no real roots

Vieta's formulas

x₁ + x₂ = −b/a · x₁ · x₂ = c/a

Sign of f(x) = ax² + bx + c

  • If Δ < 0: f(x) has the sign of a for all x.
  • If Δ = 0: f(x) has the sign of a, except f(−b/2a) = 0.
  • If Δ > 0: f(x) is opposite to a between the two roots, same as a outside.
